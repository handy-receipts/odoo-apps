How to configure and use Handy Receipts in Odoo POS

1
API Key Setup:

Install this module. Go to Odoo POS Settings, locate the 'Handy Receipts' section, and paste your API key (obtained from handyreceipts.co.in).

2
Cashier Input:

During checkout on the Odoo Payment Screen, a new touch-friendly input field will appear. The cashier types the customer's 10-digit mobile number or 4-digit pairing code.

3
Validate & Send:

Click 'Validate'. Odoo instantly pushes the payload to the Handy Receipts server asynchronously, ensuring zero delay for the cashier queue.

Frequently Asked Questions

Common queries about the Odoo Digital Receipt Integration

How to send WhatsApp receipts from Odoo POS?

By installing the Handy Receipts module, you add a mobile number input field directly to the Odoo payment screen. Upon validation, the receipt is automatically generated and sent via WhatsApp/SMS.

What happens if the POS loses internet connection?

The module features Offline Resilience. If the internet drops, receipts are queued locally and automatically sent to customers when the connection is restored.

Do I need to pay per receipt for WhatsApp?

No. The Handy Receipts platform operates on a disruptive flat-rate pricing model (starting at ₹1,200/year for Indian retailers), meaning no unpredictable per-message API fees in year one.
